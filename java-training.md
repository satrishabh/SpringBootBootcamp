# Java Training Guide

## 1. Overview
Java is a widely used object-oriented programming language designed for portability, performance, and scalability. This guide covers essential concepts for beginners and intermediate learners.

## 2. Setup
- Install Java Development Kit (JDK) 17 or newer.
- Set `JAVA_HOME` to the JDK installation directory.
- Add `JAVA_HOME\bin` to your `PATH`.
- Use an IDE like IntelliJ IDEA, Eclipse, or VS Code with the Java extension.

## 3. Java Basics
- `class` and `main` method
- Variables and data types: `int`, `long`, `double`, `boolean`, `char`, `String`
- Operators: arithmetic, comparison, logical, assignment
- Control flow: `if`, `else`, `switch`, `for`, `while`, `do-while`

## 4. Object-Oriented Programming
- Classes and objects
- Constructors
- Methods and return types
- Encapsulation and access modifiers: `public`, `private`, `protected`, default
- Inheritance and `extends`
- Polymorphism and method overriding
- Abstraction with `abstract` classes and interfaces

## 5. Common Java APIs
- `java.lang` basics: `String`, `Math`, `System`
- Collections: `List`, `Set`, `Map`, `ArrayList`, `HashMap`
- Exception handling: `try`, `catch`, `finally`, `throw`, `throws`
- I/O basics: `java.io` and `java.nio`

## 6. Advanced Topics
- Generics
- Lambda expressions and functional interfaces
- Streams API
- Multithreading basics: `Thread`, `Runnable`, synchronization
- Java modules

## 7. Best Practices
- Follow naming conventions: classes start with uppercase, variables and methods use camelCase
- Keep methods small and focused
- Use comments and meaningful variable names
- Practice code reuse and avoid duplication

## 8. Practice Exercises
1. Write a program to reverse a string.
2. Build a simple calculator using methods.
3. Create a `Person` class and manage a list of people.
4. Read and write text files.
5. Implement a basic inventory using a `Map`.

## 9. Learning Resources
- Official Java Tutorials: https://docs.oracle.com/javase/tutorial/
- Java SE API documentation: https://docs.oracle.com/javase/8/docs/api/
- Online coding platforms: LeetCode, HackerRank, Codecademy

## 10. Next Steps
- Build a small Java project
- Explore Spring Boot for web applications
- Learn unit testing with JUnit
- Study design patterns and architecture
